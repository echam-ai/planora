# Fixed profile selection

Password setup/reset was retired by #120. Open `/` and choose **Hamster Knight**
or **Ech Princess**. Both profiles work without credentials, login cookies,
or an authentication secret. **Switch account** returns to the chooser.

Selection separates saved tasks, archive, chat and settings; anyone who can
reach the app can choose either profile. It is not an access-control boundary.
See [local setup](../../README.md#run-locally-on-macos) and
[deployment setup](compose-stack.md). Apply migrations before launching; existing
data belongs to Hamster Knight and Ech Princess starts empty/default.
